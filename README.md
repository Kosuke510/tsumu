# TSUMU — どこまで積める？ 🏗

タップでブロックを積み上げるだけの中毒系ワンタップゲーム。

- **ルールは3秒で分かる**: 動くブロックをタップで落とす。ズレた分は削れて、ブロックはどんどん小さくなる。乗らなかったら終わり。
- **ぴったり重ねると気持ちいい**: PERFECT判定で音が上がっていき、コンボするとブロックが少し育って復活する。
- スマホ・PC両対応／効果音つき（♪ボタンでミュート）／ベストスコア保存／結果のシェア機能

## 遊び方

`index.html` をブラウザで開くだけ。インストール・依存ライブラリ一切なし。
GitHub Pages にそのまま置けます。
